# Debut Invitation Website

A responsive, burgundy-and-gold invitation website inspired by the provided reference screenshots.

## Run locally
1. Extract the ZIP.
2. Open this folder in VS Code.
3. Open `index.html` in your browser or use Live Server.

## Included sections
- Animated envelope cover; clicking "Open Invitation" reveals the website
- Hero / introduction
- Venue section (Pablo's Events Place)
- Photo gallery with temporary Unsplash images
- 18th Lilies, 18th Wishes, 18th Treasures, 18th Gifts, and 18th Shots
- Dress code and gift guide from the supplied document
- RSVP form demo and QR code panels
- Responsive mobile navigation and scroll-reveal animations

## Update before sharing
- The celebrant's name, event date, time, address, RSVP deadline, and monogram are placeholders because they were not supplied in the document.
- Replace sample Unsplash images with the debutante's own image files. Put them in an `images/` folder and update the `src` or CSS URL.
- Confirm spelling and the final participant lists. Names are copied from the supplied Dress Code document; a few labels and list counts may need confirmation.
- Update `publishedSiteUrl` and `venueMapUrl` in `script.js` before using the QR codes.
- The RSVP form is only a front-end demo. It does not save or send responses; connect it to a form service or backend.
- Photos, Google Fonts, and QR images require internet access.
